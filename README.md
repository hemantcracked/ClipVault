## Features
- **Zero-Friction Share Overlay:** Tap **Share → Save with ClipVault** inside YouTube, Instagram, or X to download without leaving the app.
- **Floating Quick-Download Bubble:** Optional draggable overlay button for instant clipboard downloads.
- **YouTube Videos, Shorts & Audio-Only (MP3):** Choose 1080p, 720p, 480p, or MP3 audio for lectures and podcasts.
- **Instagram Reels, Posts & Carousels:** Full video + audio merging via bundled `yt-dlp` & `FFmpeg` (with 1-tap in-app engine updates).
- **X (Twitter) HD Videos & GIFs:** Ultra-fast extraction supporting multi-video tweets and quoted tweets.
- **WhatsApp & WA Business Status Saver:** Built-in Statuses tab using Android Scoped Storage (no intrusive permissions).
- **Offline Library & Built-in Player:** Searchable media vault with `1x / 1.25x / 1.5x / 2x` playback speed controls.
- **Privacy First:** 100% on-device, zero ads, zero tracking, zero analytics.

## How to Install
1. Visit the **[ClipVault Download Page](https://hemantcracked.github.io/ClipVault/)** (or go to **[Releases](https://github.com/hemantcracked/ClipVault/releases/latest)**).
2. Download the latest `ClipVault-vX.X.X.apk`.
3. Tap the downloaded APK on your Android phone (allow *"Install unknown apps"* if prompted).
4. *(Optional)* Use **[Obtainium](https://obtainium.imranr.dev/)** with this repo URL for automatic app updates.

## Tech Stack
Kotlin • Jetpack Compose • Material 3 • Hilt • Room • WorkManager • Media3 (ExoPlayer) • Retrofit/OkHttp • `youtubedl-android` (`yt-dlp` + `FFmpeg`) • Scoped Storage (`MediaStore` & SAF)

## Disclaimer
ClipVault is intended strictly for saving publicly accessible media for personal, educational, and offline viewing. Please respect content creators and applicable copyright laws.
